# Changelog

All notable user-visible changes to the Whoogle Search TOS application package.

## 0.9.0-1 — 2026-11-14

### Added
- First release. Whoogle Search (`benbusby/whoogle-search:0.9.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8132 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/whoogledocker/`.
